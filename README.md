# ReMind project page

Organization page for **Teaching Video Generators to Remember: Eliciting
Dynamic Memory for Out-of-Sight State Evolution**.

- Website: <https://remind-applied.github.io/>
- Paper: <https://arxiv.org/abs/2605.25333>
- Code: <https://github.com/Applied-Intuition-Open-Source/ReMind>
- Model: <https://huggingface.co/AppliedIntuitionResearch/ReMind>
- Dataset: <https://huggingface.co/datasets/AppliedIntuitionResearch/ReMind1M>
- Hugging Face Collection: <https://huggingface.co/collections/AppliedIntuitionResearch/remind-teaching-video-generators-to-remember-6a6cd1ff7e9a063abb7cf5eb>

The static site is stored in `docs/` and deployed with GitHub Actions.
